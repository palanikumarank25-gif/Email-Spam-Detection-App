# 📧 Email-Spam-Ham-Prediction:
1. This app machine learning model classification Email spam or ham dectetion app model.
2. This project is a machine learning web application that classifies emails as Spam or Ham (Not Spam) based on their content.

# 🚀 Features:
1. Interactive Web Interface (Streamlit). 
2. Spam/Ham Classification in real-time.
3. Preprocessing of email text (tokenization, stopword removal, TF-IDF vectorization).
4. Machine Learning Classifier (Naive Bayes / Logistic Regression / SVM).
5. Evaluation Metrics: accuracy, precision, recall, confusion matrix, ROC curve.

# 🛠️ Tech Stack:
1. Python 3.
2. Scikit-learn (ML algorithms & evaluation).
3. Pandas / NumPy (data processing).
4. NLTK / scikit-learn (text preprocessing, TF-IDF).
5. Streamlit (frontend web app).
